🎨 Palette: Add ARIA labels and titles to icon-only buttons

Added missing `aria-label` and `title` attributes to several icon-only buttons across the application (e.g. TimerWidget, PracticeUI, HelpAssistant). Fixed a React hook dependency bug in `AdaptiveCoachDemo` where `preferReducedMotion.current` was accessed during render, replacing it with state.

To ensure icon-only buttons are accessible to screen readers and provide helpful tooltips for sighted users. The hook bug was fixed to comply with React strict mode concurrent rendering requirements and pass linter checks.
