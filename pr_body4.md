💥 The Bug: In Next.js, production builds (`pnpm build`) crashed with an `ECONNREFUSED` error while attempting to pre-render the `/sitemap.xml` route. Additionally, E2E tests for the `practice` page timed out.
🔍 Root Cause: During the build step, Next.js executes the logic inside `sitemap.ts` which calls `getPublishedBlogPosts()`. This function executes a Prisma `findMany` query. Since there is no database running in the build environment, this resulted in an unhandled `ECONNREFUSED` exception which abruptly failed the build process.
🛠️ The Fix: Wrapped the Prisma `findMany` call in `src/lib/blog-posts.ts` within a `try/catch` block. If the database is unreachable (e.g., during `pnpm build`), it now safely logs the error and gracefully degrades by returning an empty array `[]` instead of crashing.
🛡️ Prevention: This follows the codebase's strict directive to never silently fail and to properly catch connection exceptions in Next.js builds. The build pipeline now succeeds completely without a live database.
